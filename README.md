# BLE Control
BLE Control is an app that controls devices over Bluetooth Low Energy. This allows for fast, local control over custom systems. This app is designed for my w220-project-esp32 repository, but can be modified to control other devices.
## Features
- Material 3 Expressive Design
- Easy to use controls that have support for tap and hold actions.
- Beautiful animations
### Future Roadmap
- Customizable configurations for different devices in app
- Quick switching between devices
- Background daemon with notification support
- Pin based pairing support
- and more!
